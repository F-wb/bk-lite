# 盛大运维系统 使用文档 · 14 运营分析

> 模块标识：`operation_analysis`　|　顶部导航入口：**运营分析**
> **适用范围**：预生产环境 `10.10.2.91` 已启用；一期正式环境（`192.168.1.11`）未启用，菜单不可见属预期。
> 运营分析是一套**自助 BI / 运维大屏**工具：把 MySQL、PostgreSQL、REST、Prometheus、Excel 等数据接入，拖拽组件拼成仪表盘/大屏。
>
> 本篇菜单与按钮文案取自预生产实测菜单与前端源码 `ops-analysis/locales`。

---

## 1. 功能概述

- **运营分析（视图）**：可视化画布，拖拽组件生成图表/大屏。
- **管理 → 数据源**：定义"从哪取数、取什么字段"。
- **管理 → 连接库**：统一管理 MySQL / PostgreSQL / REST 的地址与凭据，供数据源复用。
- **管理 → 命名空间**：管理 NATS 命名空间，数据源可指定命名空间取数。

> **三层关系（务必先理解）**：**连接库**（地址+凭据）→ 被 **数据源** 引用（+查询语句/字段定义）→ 被 **视图组件** 引用。改连接库会影响所有引用它的数据源。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「运营分析」。
- **推荐落地顺序**：连接库（或命名空间）→ 数据源 → 视图。
- 前置：
  - 被连接的数据库/REST 服务网络可达；
  - Excel 型数据源需要上传文件；
  - Prometheus 型数据源需先有可访问的地址。

## 4. 核心操作流程（按钮级）

### 4.1 配置连接库（统一管理连接）

「管理 → 连接库」页面说明：**「统一管理 MySQL、PostgreSQL、REST 的地址和凭据，供数据源复用。NATS 仍使用命名空间。」**

1. 点 **「新建连接」**（弹窗标题 **「新建连接」**），选类型并填地址与凭据，保存提示 **「创建连接成功」**。
2. 数据源侧可：
   - **「引用连接库」**：数据源直接引用已有连接；
   - **「提取到连接库」**：把数据源里已填的连接信息抽取成公共连接，便于复用。
3. **改/删连接的影响（重点）**：
   - 删除时若仍被引用：**「无法删除」**，原因提示 **「仍有 {count} 个数据源引用该连接，请先解除引用。」**
   - 编辑时提示：**「将影响 {count} 个引用该连接的数据源，修改后后续取数立即使用新配置。」**——改一次，所有引用的数据源立即生效。

### 4.2 配置命名空间（NATS）

「管理 → 命名空间」说明：**「定义不同命名空间的 NATS，在设置数据源的时候可以指定对应命名空间的数据。」**

1. 新建/编辑命名空间，保存提示 **「创建命名空间成功」/「更新命名空间成功」**。
2. 建数据源时选择对应命名空间即可取该空间的数据。

### 4.3 配置数据源（取数定义）

1. 「管理 → 数据源」→ 新建，选择**数据源类型**：
   | 类型 | 说明 |
   |------|------|
   | **MySQL** | 填地址/库/账号，按 **「查询类型」** 写查询 |
   | **PostgreSQL** | 同上 |
   | **REST** | 填接口地址与参数，可 **「添加参数」** |
   | **Prometheus** | 用 **「Prometheus 预览查询」** 验证后取数 |
   | **Excel** | 上传文件型数据源 |
2. 填写查询与**字段定义**：
   - 字段定义用于 **「维护字段名、显示名称和数据类型。预览成功后可应用预览字段；组件配置字段时会优先使用这里的显示名称和类型。」**
   - 可点 **「转换与预览」/「取样预览」** 验证：成功 **「预览成功」**，失败 **「预览失败」/「转换预览失败」**；
   - 预览成功后点 **「应用预览字段」**（提示：**「根据当前预览列写入下方「字段定义」，便于组件选择字段」**）——**这一步能省大量手填字段的工作**。
3. 未选数据源就点字段相关操作会提示 **「请先选择数据源」**；数据源没配字段时提示 **「当前数据源未配置可用字段」**。
4. **Excel 型特别注意**：
   - 提示 **「该数据源来自配置导入或尚未上传文件。请选择 Excel 文件并确认保存，处理成功后才可使用。」**
   - 必须先 **「取样预览」** 并确认可用（**「请先取样预览并确认数据可用」**）；未选文件会提示 **「请先选择 Excel 文件后再预览」**；
   - 处理失败会提示 **「请重新选择 Excel 文件后再次确认保存」**。

### 4.4 配置筛选参数

- 只有特定类型的参数能当筛选：**「只有字符串、时间范围和日期范围参数可以配置为筛选。」**（数字/布尔等不能配筛选）
- 筛选类型可选 **「时间范围」** 等。

### 4.5 制作视图 / 大屏

1. 进「运营分析」打开画布（`/ops-analysis/view`）。
2. 左侧 **「组件库」**，提示 **「拖拽组件到右侧画布」**——把组件拖进去。
3. 组件类型（界面枚举）：**指标卡/表格/折线/柱状/饼图/仪表盘/文本/拓扑图** 等；选中组件后在配置面板绑定**数据源与字段**。
4. 常用组件操作：
   - **「复制」** 节点（提示「节点复制成功」）；
   - **「删除组件」**（配置面板底部）；注意提示 **「确认从报表草稿中删除该组件吗？保存报表后删除才会生效。」**——**删了不保存等于没删**。
   - 拓扑图场景：**「连线视图」**、**「添加文本」**、**「适配视图」**，保存提示 **「拓扑图保存成功」**；未选图就保存会提示 **「请先选择要保存的拓扑图」**。
5. 阈值/映射：可 **「添加阈值」**（在该行下方）、**「添加映射规则」**（如把状态值映射成文案/颜色）；**「基础阈值不可删除」**。
6. 保存：缺必要信息时提示 **「无法保存：缺少必要信息」**；保存失败 **「保存失败」**。

### 4.6 画布设置与全屏（大屏场景）

- 页面说明：**「大屏用于固定比例展示视图，本轮支持分辨率配置、画布边界和全屏预览。」**
- **「画布设置」** 可改 **「画布尺寸」**（**「当前画布尺寸」**）与 **「画布主题」**。
- **「全屏预览」** 提供三种适配（原文）：
  - **「全屏铺满」**：拉伸到窗口边缘；
  - **按宽度**：贴住宽度、上下滚动；
  - **按高度**：贴住高度、左右滚动。
  > **「只作用于放大和分享。全屏铺满拉伸到窗口边缘。按宽度贴住宽度、上下滚动；按高度贴住高度、左右滚动。查看和编辑始终完整显示设计尺寸。」**

## 5. 字段与配置项说明（速查）

| 项 | 说明 |
|----|------|
| 连接库 | MySQL/PostgreSQL/REST 的地址+凭据，供数据源复用 |
| 命名空间 | NATS 命名空间，数据源可选空间取数 |
| 数据源类型 | MySQL / PostgreSQL / REST / Prometheus / Excel |
| 字段定义 | 维护字段名/显示名/类型；组件优先用这里的显示名 |
| 应用预览字段 | 把预览列一键写入字段定义 |
| Excel 数据源 | 必须取样预览并确认后方可使用 |
| 筛选参数 | 仅字符串/时间范围/日期范围可配筛选 |
| 组件删除 | **保存报表后才生效** |
| 全屏适配 | 铺满 / 按宽度 / 按高度，仅影响放大与分享 |

## 6. 权限要求

- 查看视图：一般用户，受视图/团队权限约束。
- 建连接库、数据源、改字段：需"运营分析管理员"或数据分析角色。
- 连接库被多个数据源引用，改动影响面大，建议管理员统一维护。

## 7. 常见问题（FAQ）

**Q：数据源建好了，但组件里选不到字段。**
A：没做「字段定义」。先「取样预览」成功 → 点「应用预览字段」写入字段定义；未选数据源会提示"请先选择数据源"。

**Q：删了连接库提示"无法删除"。**
A：仍有数据源引用。提示会给出数量**「仍有 {count} 个数据源引用该连接，请先解除引用。」** 先去数据源改成其他连接或解除引用。

**Q：改了连接库，会不会影响别的报表？**
A：会。编辑时提示**「将影响 {count} 个引用该连接的数据源，修改后后续取数立即使用新配置。」** 改前评估影响面。

**Q：Excel 数据源一直不可用。**
A：需"上传文件→取样预览→确认保存"三步走完；失败要重新选择文件再保存，持续失败联系管理员检查文件存储与转换服务。

**Q：组件删除了还显示。**
A：删除只改了草稿，**保存报表后才生效**（界面原文）。

**Q：某个参数配不了筛选。**
A：只有**字符串、时间范围、日期范围**三类参数能配筛选。

**Q：大屏在别人屏幕上被拉伸变形。**
A：用「全屏预览」的适配模式：铺满会拉伸变形，按宽度/按高度可保持比例并滚动。查看和编辑始终按设计尺寸完整显示。
