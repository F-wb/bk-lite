# 盛大运维系统 使用文档 · 02 配置管理（CMDB）

> 模块标识：`cmdb`　|　顶部导航入口：**配置管理**
> CMDB 是全平台的"资产真相源"：监控、告警、作业、补丁都以这里的资产为准。先用模型定义"有哪些类资产、各有哪些字段"，再录入/发现实例，最后用视图和拓扑组织消费。
>
> 本篇按钮名称、下拉选项、提示文案均取自前端源码与线上菜单实测，按此操作可一一对应到界面。

---

## 1. 功能概述

- **模型管理**：定义资产类型（主机、交换机、数据库、应用……）及其属性字段、关联关系、唯一校验规则、层级。
- **资产（实例）管理**：增删改查资产实例、批量导入导出、克隆、变更记录。
- **视图**：资产总览、应用（服务）拓扑、K8S 视图、网络拓扑、IP 视图、机房机柜、标签场景视图。
- **自动发现**：扫描发现、定期采集、自定义插件、特征库、自定义上报。
- **搜索**：跨模型全文检索资产。
- **模块关联**：把资产与监控对象打通（与监控中心联动）。
- **SSH 终端**（二开增强）：资产详情页一键唤起堡垒机终端，见 `10_二开功能`。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「配置管理」，左侧出现「搜索 / 视图 / 资产 / 管理」四个一级菜单。
- **推荐落地顺序**：`管理 → 模型管理`建模型 → `资产`录实例（或用自动发现填充）→ `视图`消费。
- 自动发现/采集的前置：先在「系统管理 → 凭据管理」备好 SNMP/SSH/API 凭据，并确保对应云区域下有**可用的接入点节点**（见 `06_节点管理`）。

## 4. 核心操作流程（按钮级）

### 4.1 新建资产模型

1. 进「管理 → 模型管理」→ 点 **「新增模型」**。
2. 填写模型基本信息：**模型名称、图标、所属分组**（分组不对可在树上点 **「新增分组」** 创建）。
3. 保存后进入模型详情，用页签逐项配置：

| 页签 | 做什么 | 要点 |
|------|--------|------|
| **属性** | 加字段：字段名、类型、是否必填、默认值、**校验规则** | 点 **「新增属性分组」** 把字段归类；未分组的字段落在详情页"基本信息"区。默认值旁有说明：**「仅在页面新增实例时，系统自动填写默认值」**——即默认值不回溯已有实例 |
| **关系** | 定义与其他模型的关系 | 点 **「新增关联」**；批量删除成功提示形如「批量删除成功，共删除 N 条模型关系」，部分失败会列出失败原因 |
| **唯一规则** | 判定"同一台资产"的字段组合 | 点 **「新建规则」**。强烈建议给主机类模型按 IP 建唯一规则，否则重复录入 |
| **自动关联规则** | 按条件自动建立实例关系 | 点 **「新建自动关联规则」** |
| **自定义采集** | 该模型的采集字段映射 | 与自动发现联动时使用 |

4. 模型级配置可整体搬迁： **「导出配置」/「导入配置」**。
5. 字段类型注意：**附件/图片字段始终可选**，且**不支持唯一、搜索、筛选与自动关联**，也不参与 Excel 导入导出。

### 4.2 手工录入资产实例

1. 「资产」→ 左侧模型树点选目标模型（如 `host`）。
2. 点顶部 **「新增」**（部分入口显示为 **「新建应用」** 这类 `新建{模型名}` 形式）打开录入表单。
3. 逐项填写：
   - 带 **红色星号** 的是必填；
   - 有 **校验规则** 的字段填错会提示 **「请输入符合校验规则的内容」**；
   - 命中 **唯一规则** 时拒绝创建，并告诉你冲突在哪个字段。
4. 保存后：
   - 提示 **「新增成功！」**；
   - 想看是否真的落库，可点 **「继续新增」** 接着录，或到列表搜索该实例。

### 4.3 导入资产（异步任务，务必理解这个模型）

> 导入**不是**点完就出结果，而是**提交后台任务**。理解这点能避免"提交了却没数据"的困惑。

1. 「资产」→ 左侧选好模型 → 点顶部 **「导入」**，弹出导入窗口。
2. **先点窗口底部的链接「导出模板」**，下载名为 `{模型ID}导入模板.xlsx` 的文件——**必须用这个模板填数据**，列名要与模型字段对应。
3. 把填好的文件 **点击或拖动到上传区**（提示文案：**「点击或拖动文件到此处上传」**）。
   上传区下方会实时限制，**必须同时满足**：
   - 格式 **仅支持 `.xlsx`**（不支持 CSV/xls）；
   - 大小 **最大 20 MiB**；
   - 数据行 **1 万行以内**；
   - **一次只能传 1 个文件**（超出会提示「仅支持 .xlsx，最大 20 MiB、1 万数据行」并拒绝入列）。
4. 点 **「提交导入」**（未选文件时该按钮是灰的、点不动）。
5. 提交成功后提示：**「任务已创建，可在导入导出记录中查看处理结果」**，窗口自动关闭。
6. 打开 **「导入导出记录」** 查看任务状态（`进行中 / 执行中 / 成功 / 失败`）：
   - 任务成功后点 **「下载文件」** 取回结果文件；
   - 有失败行时点 **「查看错误报告」** 或 **「下载错误报告」** 看逐行失败原因（报告为空会提示「错误报告里没有可展示的内容」）；
   - 排队中的任务可点 **「取消排队」**；
   - 失败的导出任务可点 **「重新提交导出」**。
7. **两个容易踩的限额**：
   - 任务并发：一人**最多 5 个**排队+执行中的任务。满了会看到提示 **「已有 5 个排队或执行中的任务，请等待完成或取消排队任务。」**（此时提交按钮不可用）；
   - 记录留存：已结束任务**只保留最近 7 天的 5 条**，过期自动清理——**导出的文件要及时下载**。
8. 删除记录时会二次确认：**「删除记录及文件？已导入的实例不会撤销。」**——删记录**不等于回滚数据**，这点很重要。

### 4.4 导出资产

1. 「资产」→ 选模型 → 先用筛选区圈定范围（导导出的是**当前筛选结果**）。
2. 点顶部 **「导出」** → 窗口里点 **「提交导出」**。
3. 同样到 **「导入导出记录」** 等任务完成，点 **「下载文件」** 取 Excel。
4. 失败时提示 **「导出失败」**，可 **「重新提交导出」**。

### 4.5 修改资产属性：两种改法

**改法 A：字段级内联编辑（改单个字段，最快）**
1. 「资产」列表 → 点某行 **「详情」** 进入 → 默认在 **「基础信息」** 页签。
2. 把鼠标移到目标字段上，字段右侧出现 **编辑（铅笔）** 图标 → 点击它，该字段变为可输入。
3. 改完点 **确认（✓）** 提交；不想改点 **取消（✕）** 放弃。
4. 保存成功提示 **「修改成功！」**；改后值立刻生效，同时写入变更记录。
5. 旁边还有 **复制** 图标，用于拷贝字段值（提示「复制成功」）。

**改法 B：批量编辑（改多个字段）**
1. 详情页右上点 **「批量编辑」** → 多个字段同时进入编辑态，部分字段以表单下拉呈现（例如变更记录里的"场景"可选 `资产生命周期` / `设备生命周期` 等）。
2. 顶部还有 **「全部展开」/「全部收起」** 用于展开/收起属性分组折叠面板。
3. 改完点 **「保存」**（按钮转圈表示保存中），放弃点 **「取消」**。

> **为什么详情页分组会折叠**：分组按模型「属性分组」配置渲染，面板标题右侧的**蓝色圆形数字**是该分组内字段数量；模型里设了 `is_collapsed` 的分组默认收起，需要看内容就点标题展开或用「全部展开」。

### 4.6 订阅资产

- 详情页点 **「订阅」**（铃铛图标）。作用是**关注这台机器**：其相关变更/告警会推送到你的通知中心（见 `09_控制台`）。值班常订自己负责的机器。

### 4.7 模块关联：把资产和监控打通

详情页下方有 **「模块关联」** 区块，四个按钮（需 Edit 权限才可见）：

| 按钮 | 作用 | 效果与注意 |
|------|------|-----------|
| **建立监控关联** | 按身份探测**已有**的监控对象，只写关联关系 | 确认框文案：**「确认将选中的 N 个资产建立监控关联？仅关联已有监控对象，不会新建。」**——**它不会创建监控对象**，只做认领 |
| **手动关联** | 手工挑一个监控对象来关联 | 打开关联选择弹窗 |
| **更换关联** | 已有关联时改绑到另一个监控对象 | 同上 |
| **解除关联** | 断开资产与监控对象的绑定 | 点击即解除 |

- 区块说明文字：**「以下为系统内置关联 ID。可点建立监控关联，按身份探测已有监控并只写关联，不会新建；ID 仍只读。」**
- 若点完发现无可认领对象，提示：**「监控中没有可认领的对象，不会新建。可从节点管理推送或扫描开通监控。」**→ 说明监控侧还没有这个对象，要去 `06_节点管理` 推送采集模块，或在监控中心建对象。
- 批量：在实例列表勾选多行后也可批量建立关联。

### 4.8 用自动发现填充资产

1. 「管理 → 自动发现 → 扫描」：配置扫描范围（IP 段/CIDR）、协议（SNMP v1/v2c/v3、SSH、API）、引用凭据、设备类型识别规则。执行后逐 IP 探测，按 OID/特征匹配类型，**自动创建或更新实例**（重复发现执行更新而非新建）。
2. 「管理 → 自动发现 → 采集」→ 点 **「新增任务」** 建采集任务：
   - 全面采集场景的说明：**「您可以根据通过创建全面采集任务，针对批量的主机采集多数资产信息。」**
   - **接入点**：界面帮助文字明确写着 **「接入点指的是发起采集任务的容器节点，在节点管理对应的云区域下配置。」**——下拉里选的是节点管理里的云区域/节点，不是随便填 IP。若该接入点没绑云区域，会报 **「当前接入点未绑定云区域，无法筛选主机模型实例」**。
   - 凭据类型按采集对象选择，每种都有官方建议（务必按提示配）：
     | 凭据类型 | 官方提示要点 |
     |---------|-------------|
     | VMware vSphere | 使用**只读角色**并开启证书校验 |
     | Redfish（物理机 BMC） | 只读账户，**固定 HTTPS**；仅在受信任管理网接自签证书时才关校验 |
     | WinRM（Windows） | 优先 **HTTPS + 证书校验**；提示「关闭证书校验存在中间人攻击风险」 |
     | 平台 API | 建议**只读/最小权限**账户并开启证书校验 |
     | Azure | 需应用 ID、客户端密钥、租户 ID，应用要有目标订阅资源读取权限；**订阅 ID 在采集任务里填** |
     | 清理策略 | 有说明 **「系统仅同步新增和更新的实例，完全忽略数据源中的删除或丢失情况。」**——想删资产得手工删，采集不会帮你删 |
3. **采集器接入与验证**：采集器部署完成后点 **「验证」**，界面提示 **「采集器部署完成后点击验证，CMDB 会查询 VictoriaMetrics 中对应上报身份的指标。」** 全部就绪后显示 **「采集器接入完成」**。
4. **首次同步等待**：新配置会有状态提示 **「等待首次同步完成后开始采集」** / **「采集正在等待当前配置版本的首次同步完成。」**——这不是故障，等一轮同步即可。
5. 「特征库」维护 SOID、端口指纹、采集工具用于设备识别；「自定义插件」导入 SNMP/脚本/HTTP 拉取插件。
6. 「自定义上报」允许外部系统按约定格式主动推资产数据。

### 4.9 查看变更记录（追溯谁改了什么）

1. 资产详情 → **「变更记录」** 页签。
2. 用 **场景** 下拉过滤（如资产生命周期 / 设备生命周期）与时间范围。
3. 列表按时间线排列，点一条进详情看**字段级 diff**（改前 vs 改后高亮对比），含操作人与时间。
4. 采集写入与页面手工修改会以不同场景标识区分，便于判断"这条改动是谁发起的"。

### 4.10 各视图的具体用法

- **资产总览**：看模型/维度分布，点数字下钻到实例列表。
- **应用拓扑（服务树）**：
  - 界面提示：**「选中系统可看其下主机汇总并新建子节点；选中应用后才能分配、转移或解除挂靠。」**
  - 也就是说：**点"系统"节点** → 只能看主机汇总、可 `新建{模型名}` / **「新建应用」** 建子节点；**点"应用"节点** → 才能做**分配 / 转移 / 解除挂靠**这些把主机挂到应用下的操作。选错节点类型是"按钮怎么灰着"的常见原因。
  - 支持 `导入` / `导出` 服务树。
- **网络拓扑**：
  - 点 **「编辑」** 进入编辑态，此时可**拖动设备**调整位置；
  - **右键设备 → 「新增连线」**，再按提示 **「请点击目标设备完成连线（按 Esc 取消）」** 点另一台设备完成连线；
  - **右键连线** 可删除连线；
  - 需要端口维度时点 **「新建端口」**；
  - 改完点 **「完成」** 退出编辑；可 **「导出图片」**。
- **IP 视图 / 机房机柜**：分别按 IP 段、按机房机架维度组织资产，单元格里可直接点击进入。
- **标签视图（场景视图）**：按标签组合过滤，保存为可复用视图，切换维度实时刷新。

### 4.11 一键 SSH 终端（二开）

1. 打开一台**含 IP 的资产详情**（host、虚拟机等均可；**IPAM 网段不支持**）。
2. 在「基础信息」页签的操作区点 **「SSH 终端」** 按钮（在「订阅」和「批量编辑」之间）。
3. 系统按资产 IP 去 JumpServer 匹配主机，在**新标签页**打开 Luna 终端。
   > 匹配规则与排障见 `10_二开功能` 第 3 节。

### 4.12 删除 / 克隆

- **删除**：列表勾选或行内操作 → 二次确认；删除实例会同步清理图数据库中的关联边。
- **克隆**：以某实例为模板新建，**唯一字段会被清空要求重填**，关联关系不复制。

## 5. 字段与配置项说明（速查）

| 位置 | 项 | 说明 |
|------|----|------|
| 模型-属性 | 校验规则 | 录入不符时提示「请输入符合校验规则的内容」 |
| 模型-属性 | 默认值 | **仅页面新增实例时生效**，不回填历史实例 |
| 模型-属性 | 附件/图片字段 | 始终可选；不支持唯一/搜索/筛选/自动关联/导入导出 |
| 模型-唯一规则 | 组合字段 | 判定"是否同一资产"（建议 IP+模型）；冲突即拒绝新建 |
| 导入 | 文件约束 | 仅 `.xlsx`、≤20 MiB、≤1 万行、单文件 |
| 导入导出记录 | 任务限额 | 每人最多 5 个排队+执行中；结束记录仅存 **7 天 5 条** |
| 资产列表 | 表头点击 | 「点击筛选{name}」快速按列过滤 |
| 详情页 | 分组面板数字 | 该属性分组的字段数量 |
| 详情页 | 模块关联 | 只"认领"已有监控对象，不新建 |
| 采集任务 | 接入点 | 是**节点管理里的容器节点**，须绑定云区域 |
| 采集任务 | 清理策略 | 只同步新增/更新，**忽略源端删除** |

---

## 6. 权限要求

- 建/改模型、改唯一规则属**高影响操作**，建议仅"CMDB 管理员"角色。
- 详情页的 **「批量编辑」「模块关联」** 等按钮需要实例的 **Edit** 权限，无权时按钮直接不显示（不是灰掉）。
- 普通运维可录实例、查视图、订阅自己的机器。
- 数据权限按组织/团队控制"能看到哪些资产"，与角色功能权限叠加（见 `01_系统管理` 4.5）。

## 7. 常见问题（FAQ）

**Q：点了「提交导入」，但列表里还是没有数据。**
A：导入是**异步任务**。到 **「导入导出记录」** 看该任务状态，仍是「进行中/执行中」就还没落库；变成功后再刷新列表。若状态失败，点 **「查看错误报告」** 看具体哪行为什么失败。

**Q：导入窗口的「提交导入」按钮点不动。**
A：两种原因——① 还没上传文件；② 已有 5 个任务在排队/执行，窗口顶部会显示 **「已有 5 个排队或执行中的任务，请等待完成或取消排队任务。」**，先取消排队或等完成。

**Q：上传 CSV 报错。**
A：CMDB 导入**只认 `.xlsx`**，且不能超过 20 MiB / 1 万行。用 CSV 的话先另存为 xlsx。

**Q：导出的文件找不到了。**
A：已结束任务**只保留最近 7 天的 5 条**记录，超期文件被清理，需重新提交导出。

**Q：删除了导入记录，之前导入的资产会消失吗？**
A：不会。确认框已明确提示 **「删除记录及文件？已导入的实例不会撤销。」** 要清数据得在实例列表删资产。

**Q：自动发现扫不到设备。**
A：依次排查——① 扫描范围/协议；② 凭据是否可用（注意各凭据类型的 HTTPS/证书校验建议）；③ **接入点是否绑定云区域**（未绑会直接报「当前接入点未绑定云区域，无法筛选主机模型实例」）；④ 采集节点是否在线（`06_节点管理`）；⑤ 新配置可能处于「等待首次同步完成」。

**Q：源端已经下线的机器，采集后 CMDB 里还在。**
A：设计如此。采集**只同步新增和更新，完全忽略数据源的删除/丢失**，需手工清理。

**Q：点了「建立监控关联」，监控里却没多对象。**
A：该按钮**只认领已有监控对象、不新建**。提示「监控中没有可认领的对象，不会新建」时，要先从节点管理推送采集模块或扫描开通监控。

**Q：应用拓扑里"分配/转移"按钮是灰的。**
A：你选中的是**系统节点**而非**应用节点**。服务树规则：**选中系统**只能看主机汇总和新建子节点；**选中应用**才能分配、转移、解除挂靠。

**Q：同一台机器出现两条重复记录。**
A：多为唯一规则没配。到模型「唯一规则」按 IP 建规则，再合并/删除多余实例。

**Q：改了模型加了字段，实例详情页看不到。**
A：确认字段归到了哪个**属性分组**（未分组落在"基本信息"），并注意默认值**只对新页面新增生效**；分组收起时点 **「全部展开」**。

**Q：点 SSH 终端提示找不到资产。**
A：堡垒机侧资产 `address` 或 `name` 需与 CMDB 主机 IP **精确一致**（先 address 后 name）。网关端口映射的填法见 `10_二开功能` 3.3。
