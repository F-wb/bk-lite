# 盛大运维系统 使用文档 · 03 监控中心

> 模块标识：`monitor`　|　顶部导航入口：**监控中心**
> 监控中心负责"把指标采上来、看得懂、出问题能告警"。数据源是 CMDB 资产 + 采集器（节点管理下发），指标存于 VictoriaMetrics，用 PromQL 查询、用策略判警，告警汇入告警中心统一处置。
>
> 本篇按钮与提示文案取自前端源码 `monitor/locales`，策略表单字段与校验原文均按界面给出。

---

## 1. 功能概述

- **视图**：主机/MySQL/Redis/MongoDB/Nginx/ES/PostgreSQL/进程/网站/Ping/TCP 等预置仪表盘 + 自定义视图。
- **搜索**：PromQL 指标查询出图。
- **事件**：告警列表、策略组、单策略、策略模板（**策略是本模块核心**）。
- **集成**：采集集成（配置/指标/采集）、资产、分组、对象。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「监控中心」。
- **前置条件链**（缺一环就没数据）：CMDB 有资产 → 该资产主机上采集器在线（`06 节点管理`）→ 已配采集集成与参数 → 指标写入后有 <30s 延迟。
- 若界面提示 **「暂无通知渠道，可去…」** → 告警无法通知，先去「系统管理 → 通知渠道」配好。

## 4. 核心操作流程（按钮级）

### 4.1 配好采集（集成）

1. 「集成 → 集成」新建或进入某集成，按三个内页签配：
   - **配置**：采集插件 + 协议（SNMP v1/v2c/v3 / SSH / API）；
   - **指标**：要采哪些指标；
   - **采集**：采集间隔与参数。
2. 「集成 → 对象」定义监控对象类型并绑定插件与指标模板；「资产/分组」把配置挂到具体 CMDB 资产与分组。
3. 保存/下发后，采集组件自动加载。

### 4.2 创建一条监控策略（重点，字段最多）

1. 「事件 → 单策略」→ 点 **「创建策略」** 打开策略表单。
2. 按顺序填写（表单有多种告警类型，下面是最常用的**阈值型**）：

| 表单项 | 怎么填 / 含义 |
|--------|--------------|
| **监控对象 / 指标** | 选对象与指标；可先写 **PromQL**（输入框提示：**「请参考 Prometheus 的语法撰写 PromQL，通常可以查询并过滤相关的指标。」**） |
| **检测频率** | 多久执行一次检测 |
| **检测周期（检测窗口）** | **「请选择检测周期，用于测量收集监控数据的时间范围。」** |
| **检测方法** | **「请选择检测方法，用于计算检测周期内的所有数据。」**（如取最大值/平均值等） |
| **汇聚周期** | **「检测时收集向前覆盖一个汇聚周期的监控数据进行分析。」**；同一策略的汇聚周期决定数据如何按周期归集 |
| **分组维度** | **「监控策略根据所选分组维度分析指标，未指定的维度数据将统一聚合处理。」**——不选维度会把所有实例数据混在一起算 |
| **告警阈值 + 告警级别** | 每个级别分别填阈值；**「请至少填写一个告警级别的阈值」** |
| **持续时间** | **「N 个汇聚周期结果满足告警阈值，触发告警。」**——用持续时间过滤瞬时抖动 |
| **恢复阈值** | 低于/高于该值才恢复；**「N 个周期不满足阈值时，则告警自动恢复。」** |
| **通知 / 配置通知** | 选通知渠道与通知人（**「请输入通知者，按回车键添加」**） |

3. 点保存；策略可在列表中 **启用/停用**。
4. **阈值单位要特别注意**（官方提示原文）：
   - **「阈值单位仅用于输入和展示；告警判断时会自动换算为计算单位。仅可选择相同量纲的单位。」**
   - **「百分比请注意：percent 为 0–100，percentunit 为 0.0–1.0，请按所选单位填写。」**——填 50 表示 50%，若单位选了 `percentunit` 应填 0.5。
5. **速率类指标**：若基础查询里已含 `rate/irate/increase`，再选"速率"会报 **「基础查询已包含 rate/irate/increase，不能再选速率」**——二选一。

### 4.3 其它告警类型怎么配

| 类型 | 何时用 | 关键点 |
|------|--------|--------|
| **阈值** | 指标越线 | 最常用，见 4.2 |
| **无数据（数据缺失）** | 迟迟不上报 | 文案 **「当检测指标最近 N 分钟查询结果为空时…」**；**恢复窗口「无数据告警发出后，这段时间里又能查到数据，才自动恢复。不能长于检测窗口。」** |
| **趋势预测** | 水位上升逼近上限 | 界面提示：**「只适用于水位上升逼近上限（例如磁盘用量逼近容量），不适用于水位下降（例如可用空间距 0）。阈值只允许小于/小于等于。」** |
| **同比/环比** | 与历史时段偏离 | 需选**对照**方式与**比较值类型**： |
| 　· **Δ 差值** | **「和对照相差多少，阈值用指标原来的单位。例如使用率从 40% 到 50%，差值是 10。」** |
| 　· **% 变化率** | **「(现在 − 对照)/对照 × 100，阈值固定为 %。例如 40% 到 50%，变化率是 25%。」** |
| 　· **倍数** | **「现在 ÷ 对照，阈值是纯数字，不带单位。」** |
| 　· **直接比较** | **「直接拿窗口结果和阈值比较。」**（不选对照） |

### 4.4 策略试运行（上线前必做）

1. 在策略上点 **试运行**，指定历史时间范围。
2. 系统回放历史数据，列出"本会命中阈值"的告警列表（结果里会标注 **命中阈值**）。
3. **试运行不产生真实告警**，用来验证阈值是否合理；满意了再启用。

### 4.5 批量配置（策略模板/策略组）

- 「策略模板」建通用模板（如同一套 CPU/内存阈值规则）。
- 「策略组」把模板绑定到一批资产/分组，实现**批量生效**，不必一台台配。
- 修改模板/组会影响其下所有策略，改前想清楚影响面。

### 4.6 查看指标（视图与搜索）

- **视图**：选 `host`/`mysql`/`redis`/`nginx`… 等仪表盘；主机视图有 CPU/内存/磁盘/网络 **Top N** 排行，可切 **Top 10 / Top 20 / Top 50**，实时刷新。
- **搜索**：输入 PromQL + 时间范围 → 出折线/柱状/堆叠图；常用查询可保存为自定义图表/仪表盘。

### 4.7 查看与处理监控告警

- 「事件 → 告警」看监控侧告警；每条告警产生时会存**指标快照**（含告警前后各约 15 分钟数据）便于回溯。
- 处置动作（认领/关闭/屏蔽/升级为事故）在**告警中心**做，见 `04 告警中心`。

### 4.8 K8s 监控

- 「集成」选 K8s 类对象，填集群连接信息（支持 K3s 快速接入），采 Node/Pod/Container 指标，在对应仪表盘按集群/Node/Pod 看。

### 4.9 采集连通检测

- 对某实例点「连通性检测」：失败会诊断（网络/凭据/插件）并给修复建议，自动重试（上限 3 次）。
- 这是排查"有资产没数据"的第一站。

## 5. 字段与配置项说明（速查）

| 项 | 说明 |
|----|------|
| 汇聚周期 vs 检测周期 | 检测周期=取数时间窗；汇聚周期=按周期归集后再判断 |
| 持续时间 | 连续 N 个汇聚周期满足才告警，抗抖动 |
| 恢复阈值 | 满足条件才恢复，避免反复抖动 |
| percent / percentunit | 0–100 用 percent；0.0–1.0 用 percentunit |
| 分组维度 | 不选=所有实例混合聚合，选错会算错 |
| 趋势预测阈值 | 只允许 < 或 ≤ |
| 告警快照 | 告警前后各约 15 分钟指标数据 |

## 6. 权限要求

- 查看视图/告警：一般运维（受数据权限约束）。
- 新建/改策略、配采集集成：需"监控管理员"角色。
- 采集器安装与在线由「节点管理」负责。

## 7. 常见问题（FAQ）

**Q：主机在 CMDB 里，但监控查不到数据。**
A：按链路查——① 采集器是否在线（`06 节点管理`）；② 采集集成是否配好；③ 用「连通性检测」看失败原因；④ 新装采集有 <30s 写入延迟。

**Q：保存策略报"请至少填写一个告警级别的阈值"。**
A：每个你勾选的告警级别都要填对应阈值，不能留空。

**Q：填了 50 却按 0.5% 判警，半天不触发。**
A：阈值单位选错了。`percent` 是 0–100，`percentunit` 是 0.0–1.0，按所选单位填数。

**Q：选了"速率"报错。**
A：基础查询里已含 `rate/irate/increase`，不能再叠加速率函数，去掉其中一个。

**Q：告警太吵，反复触发恢复。**
A：① 加**持续时间**（连续 N 周期满足才告警）；② 设合理**恢复阈值**；③ 在告警中心配聚合降噪（`04 告警中心`）；④ 先用**试运行**验证阈值。

**Q：机器断连很久了却没告警。**
A：这是"数据缺失"场景，阈值型策略不覆盖。要另建**无数据告警**：设"最近 N 分钟查询结果为空"触发，并配恢复窗口（不能长于检测窗口）。

**Q：磁盘用量趋势预警配不上去。**
A：趋势预测只支持"水位上升逼近上限"，且阈值只能 `<` / `≤`（提示原文），下降趋势不适用。

**Q：想批量给一批主机加同样的 CPU 告警。**
A：建「策略模板」+「策略组」批量绑定资产/分组，避免逐台手配。

**Q：网络设备指标不全。**
A：确认选对厂商插件、SNMP 版本与凭据；自定义设备导入自定义插件或配 SNMP Trap。
