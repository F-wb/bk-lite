# 盛大运维系统 使用文档 · 13 MLOps（算法能力）

> 模块标识：`mlops`　|　顶部导航入口：**MLOps**
> **适用范围**：预生产环境 `10.10.2.91` 已启用；一期正式环境（`192.168.1.11`）未启用，菜单不可见属预期。
> MLOps 提供 6 类算法能力的"数据 → 训练 → 发布 → 调用"闭环。**6 个子模块的操作流程完全一致**，只是算法类型不同。
>
> 本篇菜单与按钮文案取自预生产实测菜单与前端源码 `mlops/locales`。

---

## 1. 功能概述

6 个算法子模块（顶部/左侧各一个入口）：

| 子模块 | 路径 | 适用场景（界面原文摘要） |
|--------|------|------------------------|
| **异常检测** | `/mlops/anomaly_detection` | 识别指标/时序异常 |
| **时序预测** | `/mlops/timeseries_predict` | **「基于历史监控数据预测未来趋势，支持容量规划、资源预调度、告警阈值动态调整等场景。」** |
| **日志聚类** | `/mlops/log_clustering` | **「对海量日志进行智能聚类，自动归纳日志模式，帮助发现隐藏问题、减少告警噪音、加速故障排查。」** |
| **文本分类** | `/mlops/classification` | 文本归类 |
| **图片分类** | `/mlops/image_classification` | **「识别运维相关图像内容，如机房设备状态、仪表盘截图、拓扑图分类等。」** |
| **目标检测** | `/mlops/object_detection` | **「检测图像中的特定目标，如机柜标签识别、设备定位、异常指示灯检测等，适用于数据中心巡检场景。」** |

每个子模块结构相同，含 5 个页签：**数据集 / 数据标注 / 训练任务 / 能力发布 / 算法配置**。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「MLOps」→ 选某个算子模块（如"异常检测"）。
- **前置条件**：
  1. 「算法配置」里已有可用算法（Docker 镜像）；
  2. 准备好数据文件（按算法类型：**表格类只支持 `.csv`**，**文本类只支持 `.txt`**）；
  3. 训练执行依赖后端算力/容器运行环境。
- 若容器未运行，能力发布时提示 **「容器未运行，无法启用发布。请先启动服务。」**

## 4. 核心操作流程（按钮级，6 个算子通用）

### 4.1 准备算法配置

1. 「算法配置」→ 点 **「新增算法配置」**（编辑用 **「编辑算法配置」**）。
2. 填 **「Docker 镜像」**：说明原文 **「用于训练和推理的 Docker 镜像完整地址，包含仓库地址、镜像名和标签」**。
3. 配置 JSON 参数：
   - 提示 **「请在表单配置标签页中编辑 JSON 配置」**（即用表单页编辑，不要直接改原始 JSON）；
   - 有超参如 **「超参数搜索的评估轮次」**：说明 **「值越大搜索空间越充分，但训练时间越长。推荐范围：50-200」**。
4. 删除配置需确认 **「确定要删除算法配置吗？此操作不可恢复。」**

### 4.2 上传数据集

1. 「数据集」→ 点 **「上传」**。
2. 把文件/文件夹**拖到上传区**（提示 **「拖动文件到此处上传」/「拖动文件夹到此处上传」**）。
3. 格式限制（严格）：
   - 表格类：**「仅支持上传csv文件」**
   - 文本类：**「仅支持上传txt文件」**
   - 传错会报 **「上传错误」**；未选文件提示 **「请上传文件」**。
4. 上传成功提示 **「上传成功」**，上传中显示 **「上传中...」**。
5. 数据集有**版本管理**（「数据集版本管理」）；「编辑数据集」可改名等。

> **删除数据集要非常小心**：确认框原文 **「确认删除该数据集吗？此操作不可恢复，使用了此数据集的训练任务和能力发布将会被一起删除。」**——会**级联删除**训练任务与能力发布。

### 4.3 数据标注

1. 「数据标注」页：列表显示 **「未标注 / 已标注」** 状态。
2. 逐条点 **「标注」**，完成后在 **「标注结果」** 查看。
3. 训练集/验证集划分在训练任务里配置（见 4.4）。

### 4.4 创建并执行训练任务

1. 「训练任务」页说明：**「管理训练任务，支持任务创建、执行和查看训练结果。」**
2. 点 **「新增训练任务」**（改配置用 **「编辑训练任务」**）：
   - 选 **「数据训练集」**（提示「请选择数据训练集」）与训练数据参数；
   - 训练文件：**「选择一个训练文件」**，并选 **「训练文件类型」**；
   - 设置 **训练集 / 验证集** 划分；
   - 需要调参时设 **「超参数搜索的评估轮次」**（推荐 50–200）。
3. 点开始训练，确认 **「确认开始训练？」**
4. 任务状态跟踪：
   - `待训练 → 训练中 → 完成`
   - 异常：**「训练失败」**、**「训练终止」**
5. 中途停止：**「停止后训练任务将终止，状态将重置为待训练。」**
6. 删除训练记录：**「删除后该训练记录将无法恢复。」**
   > **删除训练任务有级联影响**：提示 **「删除该训练任务会同时将能力发布中关联的模型服务删除，请确认能力发布中的没有需要关联此训练任务的模型服务后删除。」**

### 4.5 发布能力（能力发布）

1. 「能力发布」页说明：**「管理模型服务，包括模型部署与发布等。」**
2. 点新增 → 填 **「能力名称」**（**「能力配置」** 弹窗），选 **「训练任务」**（提示「请选择训练任务」）。
3. **模型服务端口**：**「用于指定模型服务的运行端口。若留空，系统将自动分配一个可用端口。」**
4. 发布开关：**「用于控制此能力是否对外开放的选项。」**
   - 容器没起来时无法启用：**「容器未运行，无法启用发布。请先启动服务。」**
5. 版本与状态：
   - 版本号用**语义化版本**：**「请输入语义化版本号，例如: v1.0.0」**；
   - 状态：`待发布 → 发布中 → 已发布`，失败为 **「发布失败」**；
   - 旧版本归档提示 **「归档后该版本将标记为旧版本」**。
6. 删除模型需确认 **「你确认要删除这个模型吗？」**

## 5. 字段与配置项说明（速查）

| 项 | 说明 |
|----|------|
| 算法配置 | Docker 镜像完整地址（仓库+镜像名+tag） |
| 超参数评估轮次 | 推荐 50–200，越大越充分但更慢 |
| 数据格式 | 表格类仅 csv；文本类仅 txt |
| 数据集删除 | **级联删除**训练任务与能力发布 |
| 训练任务删除 | 会同时删除关联的模型服务 |
| 训练集/验证集 | 在训练任务里划分 |
| 能力端口 | 留空自动分配可用端口 |
| 版本号 | 语义化版本，如 v1.0.0 |
| 对外开关 | 控制能力是否对外开放；容器未运行不可启用 |

## 6. 权限要求

- 上传/标注数据、建训练任务：算法/数据工程角色。
- 发布能力（对外开关）、改算法配置：需 MLOps 管理员。
- 删除数据集/训练任务属**级联高危操作**，建议限定授权并二次确认。

## 7. 常见问题（FAQ）

**Q：上传报"上传错误"。**
A：格式不符。表格类**只支持 `.csv`**，文本类**只支持 `.txt`**；用"拖动文件到此处上传"而非其他方式也可能影响。

**Q：训练一直失败或终止。**
A：① 数据集为空/未标注；② 训练文件未选或类型不符；③ 算法镜像不可用；④ 资源不足。看训练记录的状态与日志。

**Q：能力发布启用不了。**
A：提示 **「容器未运行，无法启用发布」** 时先启动服务；同时确认已选训练任务、端口配置合理（留空会自动分配）。

**Q：删了训练任务后，已发布的模型不能用了。**
A：设计如此——删除训练任务会**同时删除能力发布里关联的模型服务**。删除前务必先解绑/确认无依赖。

**Q：删数据集影响范围有多大？**
A：会**级联删除**所有使用它的训练任务与能力发布。删前先确认无在用依赖。

**Q：端口冲突/连不上服务。**
A：端口留空让系统自动分配最省事；手工指定时要确认端口未被占用且未被防火墙拦截。

**Q：6 个算子要各写一遍流程吗？**
A：不用。**6 个算子操作完全一致**（数据集→标注→训练→发布→算法配置），只是算法与数据类型不同。
