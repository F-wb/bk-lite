# 盛大运维系统 · 使用文档（索引）

面向**最终用户与运维人员**的按功能模块操作手册。

> **编写口径**：菜单与页面路径取自**线上实测** `/api/menu`；**按钮名称、下拉选项、校验与提示文案取自前端源码 locales**（`web/src/app/<模块>/locales/zh.json`）与关键组件，因此按本手册可一一对应到界面。
>
> 每篇统一结构：**功能概述 → 入口与前置条件 → 页面导航地图 → 核心操作流程（按钮级） → 字段与配置项说明 → 权限要求 → 常见问题**。

## 环境覆盖说明

| 环境 | 说明 |
|------|------|
| **预生产 `10.10.2.91`** | **16 个模块全部启用**（含 APM/RUM/MLOps/运营分析/OpsPilot/编排中心） |
| 一期正式环境（`192.168.1.11`） | 仅启用前 9 个模块；后 6 个模块菜单不可见属预期 |

> 11～16 篇按**预生产实际界面**编写，供试用与后续启用参考；正式环境启用这些模块后即可直接复用。
