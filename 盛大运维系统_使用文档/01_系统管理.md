# 盛大运维系统 使用文档 · 01 系统管理

> 模块标识：`system_mgmt`　|　顶部导航入口：**系统管理**
> 系统管理是全平台的"地基"：账号、组织、权限、登录方式、通知渠道、凭据、审计都在这里配置。其他模块的"能看到什么、能做什么"都由本模块决定。
>
> 本篇按钮名称、提示文案取自前端源码 `system-manager/locales`，与界面一一对应。

---

## 1. 功能概述

- **用户管理**：账号增删改查、组织架构、登录认证绑定、外部用户同步、安全策略、超级管理员。
- **应用管理**：角色（功能权限）、数据权限（数据范围）、自定义菜单；也是**控制模块入口可见性**的地方。
- **通知渠道**：统一维护飞书/企业微信/邮件/Webhook，供告警、作业复用。
- **集成中心**：第三方对接实例（钉钉、JumpServer 等）。
- **凭据管理**：加密存储运维账号密码/密钥/Token。
- **平台管理**：审计日志、错误日志、网络白名单、API 文档、API 令牌。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「系统管理」。
- **前置条件**：本模块是高敏管理功能，默认仅**超级管理员/系统管理员**角色可完整操作。
- 界面出现 **「当前绑定实例不可用」/「集成实例已禁用」/「集成实例的登录认证能力已禁用」** 之类提示，说明依赖的集成实例被禁用或能力未就绪，需先去集成中心检查。

## 4. 核心操作流程（按钮级）

### 4.1 新增一个用户

1. 进「用户管理」→ 点顶部 **「新增用户」**（右侧表单/抽屉打开）。
2. 依次填写：

| 字段 | 说明 |
|------|------|
| **用户名** | 登录标识，全平台唯一，创建后不建议改 |
| **姓名** | 显示名 |
| **邮箱** | 用于通知/找回 |
| **手机号** | **钉钉登录靠它匹配账号，务必填真实号** |
| **密码 / 确认密码** | 两遍一致；需满足安全策略强度 |
| **角色** | 决定功能权限（能看哪些菜单、点哪些按钮） |
| **组织权限授予** | 决定数据范围（能看哪些团队的数据） |

3. 点 **保存**。用户即可用该账号登录。

> **安全提示**：若你在编辑"邮箱/手机号"等**敏感信息**时有未提交的改动，系统会拦住并提示 **「请先确认或取消敏感信息的修改」**——必须先点该字段的 ✓ 确认或 ✕ 取消，才能保存整张表单。

### 4.2 维护组织架构

- 「组织架构」以树维护部门/团队；用户管理左侧那棵树就是它。
- 点击树上某个组织节点 → 右侧列表只显示该组织下用户（用于快速定位）。
- 组织用于**数据权限按维度隔离**（`02 CMDB`、`03 监控` 等模块的"只看本团队数据"都基于此）。

### 4.3 禁用 / 启用 / 解锁 / 删除用户

行内操作会弹**二次确认**，文案分别为：
- 禁用：**「确定要禁用该用户吗？」** → 禁用后状态显示 **「已禁用」**，不能登录。
- 启用：**「确定要启用该用户吗？」**
- 解锁：**「确定要解锁该用户吗？」**（连续登录失败被锁后使用，状态显示 **「已锁定」**）
- 删除：**「确定要删除该用户吗？」**

> **删除不了？** 若提示 **「选中的用户存在同步源用户，不允许删除，请在用户同步源中删除」**，说明该用户由 LDAP/AD 等外部同步而来，必须去「用户同步」源头处理，不能在本地删。

### 4.4 批量导入用户

1. 「用户管理」→ 点 **「导入用户」**。
2. 下载模板 → 按列填写 → 上传。
3. 约束：**单次最多导入 500 名用户**（超限提示「单次最多导入 500 名用户」；空文件提示「文件中没有可导入的用户」）。
4. 提交后弹出 **「导入结果」**：
   - 全部成功：**「导入完成：成功 {count} 名用户」**
   - 部分成功：标题 **「部分用户导入成功」**，逐行列出失败原因
   - 全部失败：**「未导入任何用户」**

### 4.5 配置外部用户同步（LDAP/AD）

1. 「用户同步」→ 点 **「添加用户源」**，填连接参数与**同步策略**。
2. 支持定时同步；同步只做新增/更新，**不删除已有用户（仅标记禁用）**。
3. 同步来的用户在本地改邮箱/手机号会**立即生效**，但界面有提示：**「该用户来自外部同步。本地修改的邮箱、手机号会立即生效；若同步源下次提供对应字段，将被外部数据覆盖。」**——即下次同步可能被覆盖，长期有效请改源头。

### 4.6 绑定登录方式（登录认证）

1. 「用户管理 → 登录认证」。
2. 点新增绑定，选择已在「集成中心」创建好的实例（如钉钉），配置**字段映射**（外部字段 → 平台用户名/手机号）。
3. 保存后登录页多出对应标签页。
4. 删除绑定会确认 **「确定要删除此认证绑定吗？」**
5. 状态异常时的提示含义：
   - **「集成实例已禁用」** → 去集成中心启用实例；
   - **「集成实例的登录认证能力已禁用」/「用户同步能力未就绪」** → 实例能力没开。

> 钉钉完整对接见 `10_二开功能` 第 2 节。

### 4.7 应用管理：控制模块可见性 + 配权限

进「应用管理」，页面说明原文：**「管理平台里的各个应用，配置角色、数据权限和菜单，也可以添加新的应用。」**

**① 控制某模块是否显示（一期隐藏未启用模块就靠这里）**
- 每个应用卡片可 **「启用」**（提示 **「菜单已启用」**）或停用（提示「菜单已停用」）。
- 停用只是**前端不展示入口**，代码与数据保留——这就是一期 APM/运营分析等模块"菜单看不到"的原因。

**② 配角色（功能权限）**
1. 进某应用的「角色」→ 新建角色，填写角色名并勾选权限矩阵（按模块/操作维度）。
2. 支持 **「全权限」** 快捷授予。
3. 保存后到「用户管理」把角色分配给用户或组织。

**③ 配数据权限（数据范围）**
1. 进某应用的「数据权限」→ 对目标角色点 **「设置数据权限」**。
2. 按 **「数据权限规则」** 设定可见范围。
3. 若提示 **「没有可用的权限模块」** → 该应用未注册可授权模块；提示 **「此模块不支持指定数据编辑」** → 该模块只支持整体范围，不能细到单条。

**④ 自定义菜单**
1. 「自定义菜单」→ 可 **复制** 现有菜单（提示「菜单复制成功」）再改。
2. 编辑时界面提示：**「将左侧功能拖拽到此处添加」**；先在左侧**勾选页面**再点 **「添加已选」**（未勾选会提示「请先在左侧勾选要添加的页面」）。
3. 可维护 **「菜单结构」**（层级）、**「菜单名称」**（不超过 100 字符）、图标、排序。
4. 菜单支持 启用/停用/删除；删除确认提示 **「删除后将无法恢复，请谨慎操作」**。

### 4.8 超级管理员

- 「超级管理员」页说明：**「管理系统超级管理员，可以查看所有管理员用户，并可以取消用户的管理员权限」**，列表显示全部管理员。
- 授权时提示：**「选中的用户将被设置为超级管理员，拥有系统所有权限」**（超级管理员**拥有系统所有权限，包括管理组织、用户和访问所有应用数据**）。
- 取消授权需确认：**「确认取消管理员权限」**，说明 **「取消后该用户将失去所有管理权限。」**
- **谨慎授予**：这是最高权限，建议只给 1-2 个运维负责人。

### 4.9 配置通知渠道

1. 「通知渠道」→ 新增渠道，选类型（飞书/企业微信/邮件/Webhook）。
2. 填连接参数（SMTP、IM 的 Webhook/Token），设置团队归属。
3. 用「测试连通性」验证通过后保存。告警中心/作业发送通知时从这里选。

### 4.10 管理凭据

- 「凭据管理」新增凭据：类型 + 内容（**AES 加密，保存后不可回显明文**）+ 适用范围。
- 采集、作业、补丁、自动发现都**引用凭据**而非明文。
- 删除前会检查**引用计数**，仍被引用的不允许直接删。

### 4.11 审计与排查

| 页面 | 用途与操作 |
|------|-----------|
| **审计日志** | 全平台增删改留痕（操作人/类型/对象/详情），按对象追溯 |
| **错误日志** | 系统异常与堆栈，按级别过滤 |
| **网络白名单** | 配置允许登录的来源 IP（CIDR）；非白名单登录被拒 |
| **API 令牌** | 为外部集成生成/吊销 Token；吊销后立即失效 |
| **API 文档** | 查阅各模块 OpenAPI 用法 |

## 5. 字段与配置项说明（速查）

| 位置 | 项 | 说明/原文提示 |
|------|----|--------------|
| 用户 | 手机号 | 钉钉登录按此匹配，务必真实 |
| 用户 | 角色 vs 组织权限 | 角色=功能权限；组织=数据范围，两者叠加 |
| 敏感信息编辑 | 未提交拦截 | 「请先确认或取消敏感信息的修改」 |
| 导入用户 | 上限 | 单次最多 500 名 |
| 用户同步 | 本地改字段 | 下次同步可能被外部数据覆盖 |
| 角色 | 全权限 | 一次性授予该应用全部权限 |
| 自定义菜单 | 名称长度 | ≤100 字符 |
| 超级管理员 | 范围 | 拥有系统所有权限 |

## 6. 权限要求

- 本模块默认仅超级管理员/系统管理员可用。
- 职责分离建议：建用户分角色→系统管理员；通知渠道/凭据→模块负责人+审批；查审计→只读审计员角色。
- 普通运维只需「控制台」（见 `09_控制台`）与个人菜单。

## 7. 常见问题（FAQ）

**Q：新同事登录不上，提示账号被锁定。**
A：连续输错密码触发锁定。在用户列表点 **「解锁」**（确认「确定要解锁该用户吗？」），或重置密码。

**Q：某人能看到菜单但点进去空的/看不到某台机器。**
A：**数据权限**没覆盖，不是功能权限。到「应用管理 → 数据权限」对该角色 **「设置数据权限」**。

**Q：想让某模块从菜单消失。**
A：到「应用管理」把该应用**停用**（前端隐藏、代码数据保留），不要删代码。一期未启用模块就是这么做的。

**Q：保存用户表单报"请先确认或取消敏感信息的修改"。**
A：你有邮箱/手机号字段处于编辑态未提交。在该字段点 ✓ 确认或 ✕ 取消，再保存整表。

**Q：删用户提示"存在同步源用户，不允许删除"。**
A：该用户来自外部同步，必须去「用户同步」的源里处理。

**Q：同步来的用户改了手机号，过几天又变回去了。**
A：见 4.5——本地改动下次同步会被外部字段覆盖，请改同步源。

**Q：自定义菜单拖不进去。**
A：需**先在左侧勾选页面**再点 **「添加已选」**；直接拖拽也要保证左侧已勾选（提示「请先在左侧勾选要添加的页面」）。

**Q：取消某人管理员权限后他还说能进。**
A：确认保存成功（提示「已成功取消管理员权限」），并让其重新登录刷新权限缓存。
