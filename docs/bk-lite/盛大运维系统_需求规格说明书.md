## 1. 引言

### 1.1 目的

本文档是盛大运维系统一期的需求规格说明书（Software Requirements Specification），旨在对系统一期范围内各模块的功能需求、非功能需求和接口需求进行完整、可验证的描述，作为设计、开发、测试和验收的依据。

### 1.2 范围

本文档覆盖盛大运维系统一期交付的全部 12 个模块：

**业务模块（8 个）：** 配置管理（CMDB）、监控中心（Monitor）、日志管理（Log）、告警中心（Alerts）、应用性能监控（APM）、作业管理（Job）、节点管理（Node Mgmt）、补丁管理（Patch Mgmt）。

**基础支撑模块（4 个）：** 系统管理（System Mgmt）、控制台（Console）、运营分析（Operation Analysis）、基础设施（Core / Base / RPC）。

## 2. 总体描述

### 2.1 产品视角

盛大运维系统是一套独立的企业级运维管理平台，不依赖外部运维平台运行。系统自包含前端控制台、后端 API 服务、异步调度引擎、采集与执行代理、存储引擎等全部组件，可独立部署、独立运行。

系统对外提供 OpenAPI 接口，支持与 ITSM 工单系统、CI/CD 流水线、监控外部数据源等第三方系统集成。

### 2.2 产品功能概述

| 功能域 | 模块 | 核心能力 |
|--------|------|----------|
| 资产管理 | CMDB | IT 资产建模、实例管理、拓扑关系、自动发现、IPAM |
| 监控告警 | Monitor | 指标采集、策略告警、PromQL 查询、仪表板 |
| 日志分析 | Log | 日志采集、提取解析、全文检索、日志告警 |
| 告警处置 | Alerts | 多源告警汇聚、富化、降噪、分派、通知、事故管理 |
| 应用性能 | APM | 分布式链路追踪、服务拓扑、健康度、SLO |
| 作业执行 | Job | 脚本/Playbook 执行、文件分发、定时调度 |
| 节点管理 | Node Mgmt | 采集组件生命周期管理、跨云区域部署 |
| 补丁管理 | Patch Mgmt | 补丁扫描、合规评估、批量安装 |
| 系统管理 | System Mgmt | 用户/组织/权限/登录/通知/凭据/审计 |
| 控制台 | Console | 通知聚合、个人中心、应用集 |
| 运营分析 | Operation Analysis | 画布大屏、数据源、报表中心 |
| 基础设施 | Core/Base/RPC | 认证/调度/OpenAPI/NATS/国际化 |

## 3. 功能需求 — 业务模块

### 3.1 配置管理（CMDB）

#### FR-CMDB-001 模型管理 — 模型定义

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-CMDB-001 |
| **需求名称** | 资产模型定义 |
| **优先级** | 高（P0） |
| **描述** | 用户可定义资产模型（如主机、交换机、存储等），包括属性字段、关联关系、唯一校验规则，支持字段分组与模型层级 |

**输入：** 模型名称、模型图标、模型分组、属性字段列表（字段名、类型、是否必填、默认值、校验规则）、关联关系定义、唯一规则。

**处理逻辑：**
1. 校验模型名称唯一性
2. 校验字段名不重复且符合命名规范
3. 创建模型记录及关联属性字段
4. 建立模型层级关系（父子模型）
5. 在图数据库中创建对应节点标签

**输出：** 模型对象（含模型 ID、字段定义、关联关系）。

**验收标准：**
- 创建模型后可在实例管理中引用该模型
- 模型字段修改后已有实例同步更新
- 唯一规则冲突时返回明确错误提示
- 支持模型的导入导出

#### FR-CMDB-003 实例管理 — 实例 CRUD

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-CMDB-003 |
| **需求名称** | 资产实例增删改查 |
| **优先级** | 高（P0） |
| **描述** | 用户可对资产实例进行创建、查询、修改、删除操作 |

**输入：** 模型 ID、实例属性值、拓扑挂载节点、关联实例。

**处理逻辑：**
1. 校验必填字段与唯一规则

**验收标准：**
- 创建实例后可在列表和拓扑中检索到
- 修改实例属性后变更历史可追溯
- 删除实例后图数据库关联边同步清理
- 唯一规则冲突时拒绝创建并提示冲突字段

#### FR-CMDB-004 实例管理 — 批量导入导出

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-CMDB-004 |
| **需求名称** | 资产实例批量导入与导出 |
| **优先级** | 高（P0） |
| **描述** | 支持通过 Excel/CSV 文件批量导入资产实例，支持按条件批量导出实例数据 |

**输入：** 导入：Excel/CSV 文件（含模型字段列）；导出：模型 ID、过滤条件。

**处理逻辑：**
1. 解析文件，逐行映射到模型字段
2. 校验字段类型与唯一规则
3. 批量写入实例，记录成功/失败行数
4. 导出时按过滤条件查询实例并生成 Excel 文件

**输出：** 导入结果报告（成功数、失败数、失败详情）；导出文件下载链接。

**验收标准：**
- 导入支持最多 10000 行数据
- 导入失败行有详细错误描述
- 导出文件包含模型全部字段
- 导入操作记录到操作审计日志

#### FR-CMDB-008 自动发现 — 扫描发现

| 项目 | 内容 |
|------|------|
| **需求编号** | FR-CMDB-008 |
| **需求名称** | 自动扫描发现设备 |
| **优先级** | 高（P0） |
| **描述** | 通过 SNMP/SSH/API 等协议自动扫描网络范围内的设备，识别设备类型并录入 CMDB |

**输入：** 扫描范围（IP 段/CIDR）、协议类型、凭据 ID、设备类型识别规则。

**处理逻辑：**
1. 遍历扫描范围，逐 IP 探测
2. 使用凭据尝试连接（SNMP/SSH/API）
3. 采集设备基础信息（SysName、SysObjectID 等）
4. 根据 OID 库或特征匹配设备类型
5. 创建或更新 CMDB 实例

**输出：** 发现设备列表（含 IP、设备类型、采集到的属性）。

**验收标准：**
- 支持 SNMP v1/v2c/v3 协议
- 发现的设备自动创建 CMDB 实例
- 重复发现的设备执行更新而非重复创建
- 支持定时扫描任务
