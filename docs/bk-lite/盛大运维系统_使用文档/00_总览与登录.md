# 盛大运维系统 使用文档 · 总览与登录

> 本文档面向**最终用户与运维人员**，是整套《使用文档》的第 0 篇（总览）。
> 建议先读完本篇熟悉登录、界面布局与通用操作约定，再按需查阅对应模块分册。
> 文档基于二开交付版本 `shengda/v1.0-custom`（一期已交付验收），菜单与页面路径以线上实例实测为准。

---

## 1. 系统是什么

「盛大运维系统」是一套一体化 IT 运维平台，把配置管理、监控、告警、日志、作业、补丁等运维日常能力聚合在一个门户里，统一账号、统一权限、统一导航。

一期正式启用以下 **9 个功能模块**（本套文档逐一覆盖）：

| 模块 | 一句话用途 | 分册 |
|------|-----------|------|
| 系统管理 | 用户、组织、角色权限、登录认证、通知渠道、凭据、审计 | `01_系统管理` |
| 配置管理（CMDB） | 资产的模型定义、实例台账、拓扑与自动发现 | `02_配置管理CMDB` |
| 监控中心 | 指标采集、监控策略、仪表盘与指标查询 | `03_监控中心` |
| 告警中心 | 告警接入、富化降噪、分派通知、事故处置 | `04_告警中心` |
| 日志中心 | 日志采集、检索分析、日志告警 | `05_日志中心` |
| 节点管理 | 采集节点/云区域、采集器与控制器的安装运维 | `06_节点管理` |
| 作业管理 | 脚本/Playbook、批量执行、文件分发、定时任务 | `07_作业管理` |
| 补丁管理 | 补丁源、补丁库、合规基线与批量安装 | `08_补丁管理` |
| 控制台 | 通知中心与个人工作台 | `09_控制台` |

二开增强功能（品牌、钉钉登录、堡垒机 SSH 终端）见 `10_二开功能`。

> **关于未启用模块**：APM、RUM、MLOps、运营分析、OpsPilot（AI）、编排中心等模块一期未启用，其入口已在「系统管理 → 应用管理」中隐藏，菜单不可见、直接访问会提示无权限或不存在，属**预期行为**，本套文档不予收录。

## 2. 访问地址与浏览器要求

- **访问地址**：`https://<系统地址>/`（例如测试环境 `https://192.168.1.11/`，生产以实际下发地址为准）。
- 使用**HTTPS** 访问。若地址为 IP 且证书为自签名，浏览器首次会弹「连接不是私密连接/证书无效」提示，点击「高级 → 继续前往」即可（这是内部环境的正常现象）。
- 推荐使用较新版本的 **Chrome / Edge** 浏览器；分辨率建议 1280×720 及以上，过低分辨率下顶部导航可能换行。
- 无需安装任何客户端插件，全部功能在浏览器内完成。

## 3. 登录

平台支持两种登录方式，登录页以**标签页**形式并列展示，默认停在第一个：

### 3.1 账号密码登录（默认方式）

1. 打开访问地址，进入登录页。
2. 选择「平台账号密码登录」标签。
3. 输入管理员分配给你的**用户名**与**密码**，点击「登录」。
4. 首次登录、或密码被重置后，系统可能要求你**修改初始密码**——按提示设置符合强度要求的新密码（长度、大小写、数字、特殊字符组合）后继续。

> 连续登录失败达到阈值（默认 5 次）会临时锁定账户；如被锁定，请联系管理员在「系统管理 → 用户管理」解锁。

### 3.2 钉钉扫码登录（如已启用）

1. 在登录页切换到「钉钉」标签。
2. 用钉钉 App 扫描页面上的二维码，或在钉钉内点击授权。
3. 系统按预先配置的字段映射（通常以**手机号**匹配平台已有账号）自动登录到你的账号。

> 钉钉登录需管理员先在「集成中心」创建钉钉实例、并在「登录认证」完成绑定后才可用。具体配置见 `10_二开功能` 第 2 节。若你扫码后提示匹配不到账号，说明你的钉钉手机号与平台账号手机号不一致，请联系管理员核对。

### 3.3 首次登录：初始化组织

首次登录会弹出 **「初始化用户配置」** 窗口（不可关闭），要求填写 **「组织名」** 后点确认。作用是为你的账号建立默认组织归属，后续**数据权限按组织生效**。填错了请联系管理员在「系统管理 → 组织架构」修正。

### 3.4 两步验证（OTP，如已启用）

若管理员为你的账号启用了 OTP，登录时在校验密码后会要求输入**动态验证码**（Google Authenticator 等 App 生成，30 秒有效）。首次启用需在「个人中心」扫码绑定密钥。

## 4. 界面布局与导航

登录成功后进入门户，界面分为三个区域：

```
┌─────────────────────────────────────────────────────────┐
│  顶部导航栏： [Logo] 盛大运维系统 | 模块切换 | 🔔通知  👤个人菜单 │
├──────────────┬──────────────────────────────────────────┤
│              │                                            │
│  左侧菜单     │              主内容区                       │
│ （当前模块下  │   （你点击的菜单对应的功能页面在这里展示）      │
│  的菜单树）   │                                            │
│              │                                            │
└──────────────┴──────────────────────────────────────────┘
```

- **顶部导航栏**
  - 最左是产品 Logo 与名称（已定制为「盛大运维系统」）。
  - 中部是**模块切换**入口——一级功能模块（系统管理/配置管理/监控中心…）在此切换；选中某模块后，左侧菜单才刷新为该模块的子菜单。
  - 右侧有：🔔 **通知铃铛**（打开**通知中心**，显示未读数）、👤 **个人菜单**（点头像展开，含个人中心、切换语言、退出登录）。这两者是**平台级入口**。
- **左侧菜单**：展示当前模块下的菜单树，支持多级折叠展开。部分详情页/编辑页不在菜单中显示（称为「隐藏页」），只能从列表点击进入。
- **主内容区**：功能页面本体。

> **重要导航约定**：一级模块在**顶部**切换，左侧是模块**内部**的菜单。新手最常见的问题是"找不到某模块"——请先到顶部导航确认模块，而不是在左侧菜单里翻找。
>
> 三个容易混淆的入口：
> - **控制台**（`/ops-console/home`）：登录后默认落地页，是**应用卡片广场**，不在左侧菜单里（详见 `09_控制台`）；
> - **通知中心**：顶部 🔔 铃铛，看告警分派/恢复、作业结果等站内通知；
> - **个人菜单**：顶部头像，改资料/密码、切语言、退出登录。

各模块的**具体菜单树与页面路径**在对应分册第 3 节「页面导航地图」列出。

## 5. 通用操作约定

所有模块的列表页交互高度一致，掌握以下几类即可通吃：

### 5.1 列表页通用元素

- **筛选栏**：页面顶部通常有条件筛选（关键字搜索框、下拉筛选、时间范围）。改条件后列表实时刷新。
- **操作按钮区**：右上或表格上方有「新建/导入/导出/批量操作」等按钮。
- **表格列**：多数列表支持自定义列显示、排序；行尾有「详情/编辑/删除」等操作列。
- **分页**：底部翻页，可切换每页条数。
- **详情跳转**：点击行或「详情」进入详情页；详情页内的子信息多以**内页签（Tab）**组织（如 CMDB 资产详情的"基础信息/关联关系/变更记录"）。

### 5.2 新建 / 编辑表单

- 标 **红色星号（\*）** 的字段为必填。
- 字段下方灰色文字是该字段的**填写说明/取值约束**，遇到不确定的字段先看这里。
- 表单保存前一般做前端校验（如名称唯一、IP 格式、Cron 表达式合法性），报错会定位到具体字段。

### 5.3 导入 / 导出

- **导入**：先「下载模板」→ 按模板列填数据 → 上传文件 → 系统逐行校验并给出"成功 N 行/失败 M 行 + 失败原因"报告。失败的行修正后可重新上传。
- **导出**：先设筛选条件圈定范围，再点「导出」，按当前条件生成 Excel/CSV 下载。

### 5.4 危险/高危操作确认

删除、批量执行、打补丁、执行含高危命令的作业等不可逆或高风险操作，会弹**二次确认**框，部分需输入对象名称确认。请仔细阅读确认内容后再操作。

### 5.5 权限不足的表现

- 看不到某菜单/某按钮 = 你的角色未被授予该功能权限；
- 看得到列表但某条数据不显示 = 数据权限范围未覆盖该条；
需要更高权限时，联系管理员在「系统管理 → 应用管理 → 角色 / 数据权限」调整。

## 6. 个人相关操作（顶部个人菜单）

- **修改个人资料 / 头像 / 邮箱 / 手机**：点顶部头像 → 个人中心修改；改邮箱/手机通常需验证码验证。
- **修改密码**：个人中心或首次登录强制修改流程。
- **通知已读/清空**：点顶部🔔铃铛打开通知中心，逐条或批量标记已读（详见 `09_控制台`）。
- **切换界面语言**：个人菜单内选择中/英。
- **退出登录**：个人菜单「退出」。

## 7. 阅读后续分册的建议路径

- **第一次接手系统**：按 `01 系统管理` → `02 CMDB` → `06 节点管理` → `03 监控` → `04 告警` 的顺序打通主干（先建用户权限、管资产、装采集、配监控、接告警）。
- **只做日常值班/告警处置**：直接看 `04 告警中心` 与 `09 控制台`。
- **做批量运维/发补丁**：看 `07 作业管理` 与 `08 补丁管理`。
- **排查"数据没有/采集不到"**：从 `06 节点管理`（采集器是否在线）与 `03 监控`（采集配置与连通检测）入手。

每篇分册结构统一为 7 节：**功能概述 → 入口与前置条件 → 页面导航地图 → 核心操作流程 → 字段与配置项说明 → 权限要求 → 常见问题**，可按需跳读。
