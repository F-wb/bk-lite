# 盛大运维系统 使用文档 · 15 OpsPilot（AI 智能运维）

> 模块标识：`opspilot`　|　顶部导航入口：**OpsPilot**
> **适用范围**：预生产环境 `10.10.2.91` 已启用可试用；一期正式环境（`192.168.1.11`）未启用。
> **项目状态提醒**：本项目一期对 AI 模块评估后**暂缓实施**（零分叉启用方案见《盛大运维系统_AI模块规划.md》）。本篇按预生产实际界面编写，供试用与后续启用参考。
>
> 本篇菜单与按钮文案取自预生产实测菜单与前端源码 `opspilot/locales`。

## 1. 功能概述

| 菜单 | 路径 | 作用 |
|------|------|------|
| **工作台** | `/opspilot/studio` | 面向"机器人/应用"的运营：设置、通道、日志、统计、接口说明、对话 |
| **智能体** | `/opspilot/skill` | 配置 LLM + 知识库 + 工具，编排问答与自动化 |
| **知识库** | `/opspilot/wiki` | **「由 AI 持续构建、以页面为中心、可被多个智能体复用的知识库」** |
| **工具** | `/opspilot/tool` | **「提供智能体外部接口调用与自动化能力」** |
| **记忆** | `/opspilot/memory` | 记忆体与长期记忆沉淀 |
| **模型** | `/opspilot/provider` | **「管理 AI 模型供应商及其 API 接入配置」** |

> **依赖顺序（强制）**：**模型供应商** → **知识库/工具/记忆** → **智能体** → **工作台/渠道发布**。没有模型，知识库和智能体都跑不起来。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「OpsPilot」。
- **前置条件**：
  1. 「模型」里已添加**至少一个可用供应商与模型**（LLM / 向量模型）；
  2. 知识库需绑定 **「推理模型」**（**「用于生成资料摘要与构建知识页面，创建后必须绑定」**）与 **「向量模型」**；
  3. 如需识图，还要配 **「图片识别模型」**（多模态）；未配时提示 **「需先在设置中配置图片识别模型」**。

## 4. 核心操作流程（按钮级）

### 4.1 添加模型供应商（第一步）

1. 「模型」→ 点 **「添加供应商」**（弹窗 **「添加供应商」**，编辑用 **「编辑供应商」**）。
2. 填 **「供应商」**、**「API Key」**（**「请输入 API Key」**）与接口基址等接入参数。
3. 保存后进「模型详情」维护可用模型列表（LLM / 向量 / 多模态）。
4. 若无模型，创建知识库/智能体时会报 **「获取LLM模型失败」** 或提示 **「请选择LLM模型」**。

### 4.2 创建知识库并构建

1. 「知识库」→ **「新建知识库」**。
2. 必填绑定（创建后**必须绑定**）：
   - **「推理模型」**：**「用于生成资料摘要与构建知识页面，创建后必须绑定」**
   - **「向量模型」**：用于检索（未配会提示 **「未配置向量模型」**）
   - 可选 **「图片识别模型」**：**「开启后解析文件时调用图片识别模型补充图片内容」**
3. **上传资料**：
   - 支持 **「点击或拖拽文件到此处上传」**；可开启 **「文件夹导入」**（整文件夹按文件名分别建资料）；
   - 也可导入网页资料（**「系统只解析当前 URL 页面。页面正文或图片较多时，解析和构建可能耗时更长并产生较多模型用量。」**）；
   - **大文件提醒**：单个文件 > **500 MB** 会弹 **「确认上传大文件」**，说明 **「以下文件大于 500 MB。确认后系统仍会完整上传、解析并构建，不会因软 token 阈值主动终止。」** 确认后点 **「继续上传」**。
4. **用途与结构**（决定知识目录）：界面提示 **「结构说明会生成知识目录。用 `- \`wiki/operations\`` 列出路径；创建或保存「用途与结构」后生效。」**
   - **目录由结构说明生成**，不是由文件夹名自动生成：**「来源文件夹仅用于保留资料来源和辅助分类，不会自动创建、重命名或决定知识目录。」**
5. 等待构建；构建完成的知识版本才能发布检索。
6. **索引维护**：可 **「重建索引」**：
   - 说明 **「重建该知识库全部启用知识页面的页面索引与分块索引,并记录构建结果用于诊断。」**
   - 确认 **「确定重建该知识库的全部索引?」**，完成提示 **「知识库索引重建完成」**
7. **归档 / 删除**：
   - 归档：**「归档后知识库只读,不再参与构建与检索」**，确认 **「确定归档该知识库?」**
   - 删除：**「一旦删除该知识库将无法恢复,请务必确认。其全部资料、知识页面与构建记录都会被永久移除。」**

### 4.3 创建智能体

1. 「智能体」→ 新建。页面说明：**「智能体包括选择LLM模型和知识库以优化语言理解和生成过程。用户还可以启用RAG（检索增强生成）和对话增强功能，以提高对话质量和准确性。」**
2. 在「设置」里配置：
   - **「LLM模型」**（必选，**「请选择LLM模型」**）；可选 **Rasa 小模型**做前置过滤：**「请为该应用选择使用的Rasa小模型，进行简单问题的过滤和闭环，减少大模型的API调用和token消耗」**
   - **知识库**（可多选，用于 RAG）；
   - **「系统提示」**：可用 **「可以输入相关的提示语，引导模型生成特定的回复应…」** 调整方向与质量；
   - **「工具」**：**「给智能体获取外部数据或者执行操作的能力，具体调用哪个工具，由大模型自主决定。」**
   - **「技能包」**：**「挂载场景技能包，注入专业运维处理逻辑与提示规则」**；未挂载显示 **「暂未挂载技能包，可点击右上角「添加技能包」进行挂载」**
   - **使用组织 / 管理组织**：**「使用组织可调用该智能体进行对话/接口请求；管理组织会自动加入且不可移除」**
3. 在 **「Web对话」** 直接试聊调优。

### 4.4 发布渠道（让别人能用）

「智能体 → 发布」提供多种渠道：

| 渠道 | 说明（界面原文要点） |
|------|---------------------|
| **嵌入式对话** | **「提供可通过 WebChat 嵌入网页的对话接口。保存渠道后即可复制下方调用地址。」**；嵌入请求需带 `Api-Authorization`（系统管理 UserAPISecret），路径含 `skill_id` 与 `channel_id` |
| **OpenAI API** | **「提供可通过OpenAI调用的接口，支持SSE流式设置。画布保存后，可点击节点查看对应调用参数如下」** |
| **平台弹窗 / Web 对话** | 平台内使用 |

- 发布后可看 **「历史」**（会话记录）。
- **API 密钥**：在密钥页 **「创建新密钥」**；提示 **「为了防止API滥用，请保护你的API密钥。」** 删除需确认 **「你确定要删除选中的密钥吗？」**

### 4.5 工作台运营（机器人视角）

- **设置**：机器人基础配置（含 Rasa 小模型、渠道等）。
- **通道**：配置对外通道；保存后可复制调用地址。
- **日志**：查看对话与调用日志。
- **统计**：**「机器人的运营统计用于分析用户对机器人的使用和调用情况。」**
- **接口说明**：查看对外调用参数。
- **对话**：直接在工作台试聊。

### 4.6 配置工具

- 「工具」用于给智能体挂载外部能力（HTTP 接口调用/自动化）。
- 配置好后在智能体的「工具」里勾选即可；运行时会看到 **「等待工具调用…」**、**「已调用 {count} 个工具」**。
- 若工具调用结束但未收到结果，会提示 **「工具调用已结束，但未收到结果事件。」**（或"流中断前未收到结果事件"）——通常是工具侧超时/接口异常。

### 4.7 配置记忆（长期记忆）

1. 「记忆 → 配置」：选择 **「记忆体」** 与写入策略。
2. **「每满该轮数后，将本会话尚未写入的对话沉淀到记忆体」**——即按轮数阈值自动沉淀长期记忆。
3. 未选记忆体时提示 **「未选择记忆体时不会沉淀长期记忆」**。
4. 可覆盖记忆合并用的大模型：**「用于记忆合并的大模型，默认使用记忆空间配置的默认模型，可在此覆盖为其他模型」**。
5. 「记忆」页可查看已沉淀条目，「记忆正文」看详情。

### 4.8 上下文用量与长对话

- 会话顶部可看 **「上下文用量」**；接近上限时提示 **「接近输入工作预算。再变长会继续压缩；系统提示和本轮问题放不下时才会失败。」**
- 关闭历史时是 **「单轮问答（不携带上下文）」**。

## 5. 字段与配置项说明（速查）

| 项 | 说明 |
|----|------|
| 模型供应商 | API Key + 接口基址，供 LLM/向量/多模态使用 |

## 6. 权限要求

- 配置模型供应商、API 密钥：需 AI 平台管理员。
- 建知识库/智能体：AI 应用管理员或算法角色。
- 使用组织可用、管理组织不可移除；跨团队使用靠"使用组织"授权。
- 一期正式环境未启用该模块，相关权限暂不生效。

## 7. 常见问题（FAQ）

**Q：创建知识库/智能体时选不到模型。**
A：先在「模型」添加供应商并配置可用模型；未配置时会提示"获取LLM模型失败"或"请选择LLM模型"。

**Q：知识库上传了资料，但知识目录是空的/和文件夹不一致。**
A：知识目录由**「用途与结构」**里的结构说明生成（`- \`路径\``），不是文件夹名。补齐结构说明并保存后生效。

**Q：上传超大文件卡很久。**
A：>500MB 会提示确认，确认后仍会完整上传解析，耗时与模型用量都较高；可拆分资料或调低单文件体量。

**Q：知识库检索不到内容。**
A：① 是否配了**向量模型**（未配会提示"未配置向量模型"）；② 知识版本是否已发布就绪；③ 可尝试**重建索引**（会记录诊断结果）。

**Q：删了知识库能恢复吗？**
A：不能。提示明确 **「一旦删除该知识库将无法恢复…全部资料、知识页面与构建记录都会被永久移除。」** 只想停用请用**归档**。

**Q：智能体回答不按运维规则来。**
A：补**系统提示**，并挂载**技能包**（"注入专业运维处理逻辑与提示规则"）。

**Q：工具调用结束但没返回结果。**
A：界面提示"工具调用已结束，但未收到结果事件/流中断"——多为工具接口超时或异常，先查工具自身的接口连通性与超时配置。

**Q：长对话后回答变差/报错。**
A：看"上下文用量"，接近预算会被压缩；系统提示+本轮问题放不下才会失败。可开新会话或精简知识注入。

**Q：别人怎么接入我的智能体？**
A：在「发布」配渠道：嵌入式（WebChat，需带 `Api-Authorization` 与路径参数）或 OpenAI 兼容接口（支持 SSE）。
