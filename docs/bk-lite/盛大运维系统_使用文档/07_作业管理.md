# 盛大运维系统 使用文档 · 07 作业管理

> 模块标识：`job_mgmt`　|　顶部导航入口：**作业管理**
> 作业管理是"批量执行动作"的引擎：把脚本/Playbook 下发到目标主机执行、批量分发文件、配定时任务。执行依赖节点管理里的控制器，凭据依赖系统管理的凭据库，目标多来自 CMDB。
>
> 本篇按钮与提示文案取自前端源码 `job/locales`。

---

## 1. 功能概述

- **首页**：执行概览（近 7/30 天趋势与成功率）。
- **作业执行**：快速执行、文件分发、定时任务、作业记录。
- **作业模版**：脚本库、Playbook 库。
- **目标管理**：静态/动态执行目标。
- **系统配置**：高危命令、高危路径检测规则。

---

## 2. 入口与前置条件

- 入口：顶部导航选择「作业管理」。
- **前置条件**：目标机控制器在线（`06 节点管理`）+ 执行凭据有效 + 有可用目标（静态主机或 CMDB 动态目标）。
- 权限：只能对**所属团队**的目标执行作业。

## 4. 核心操作流程（按钮级）

### 4.1 快速执行脚本/Playbook（最常用）

界面说明原文：**「在目标主机上快速执行脚本或 Playbook。支持从作业模版选择已有脚本，或临时输入脚本内容直接执行。」**

1. 「作业执行 → 快速执行」。
2. 选执行内容，二选一：
   - **「脚本库」**：从已有脚本选；
   - **「Playbook」**：从 Playbook 库选；
   - 或选"临时输入"，直接在 **「脚本内容」** 里写。
3. 点 **「添加目标主机」** 打开主机选择：
   - 搜索框占位 **「搜索主机名或IP，支持模糊匹配」**；
   - 勾选后显示 **「已选择 {count} 台主机」**，可 **「取消全选」**。
4. 填 **「执行参数」**：占位说明 **「脚本执行时传入的参数，同脚本在终端执行时的传入参数格式，如：./test.sh xxxx xxx xxx」**。
5. 填 **「超时时间（秒）」**：**「脚本执行超时时间，超时后将自动终止」**。
6. 点 **「立即执行」**。
7. 执行中状态 `执行中`，可实时看日志流；完成后状态 **「成功」/「失败」**。

### 4.2 中途取消执行

1. 在作业记录/执行页点 **「取消执行」**。
2. 确认框原文：**「确定取消该执行吗？已下发到目标主机的任务可能无法立即停止。」**
3. 取消后状态 `取消中 → 已取消`，并提示 **「已请求取消，远端执行可能仍在进行，等待结果回写」**。
   > 重要：取消是"请求"，**已下发到目标机的部分可能仍会跑完**，结果最后回写。

### 4.3 文件分发

界面说明原文：**「将文件或目录批量分发到目标主机，支持覆盖策略和并发控制。」**

1. 「作业执行 → 文件分发」。
2. 选**源文件或目录** → 添加目标主机 → 填 **「目标路径」**。
3. 设置覆盖策略与并发。
4. 执行后可看**每台主机成功/失败**；过期文件自动清理。
5. 分发目标路径受**高危路径规则**约束（见 4.6），命中会被拦截或二次确认。

### 4.4 定时任务

界面说明原文：**「创建和管理周期性执行的作业，支持 Cron 表达式和自定义执行策略。」**

1. 「作业执行 → 定时任务」→ 点新建（进入 `cron-task/create`）。
2. 选脚本/Playbook + 目标 + **Cron 表达式** + 执行策略。
3. 保存后由调度器按计划执行；执行时自动用团队凭据认证目标机。
4. 记录可在「作业记录」按来源 `定时任务` 过滤查看。

### 4.5 作业模版：脚本库与 Playbook 库

- **脚本库**：支持 Shell / Python / PowerShell；定义参数（名称/类型/默认值/必填）；保存后带版本号可回溯。
- **Playbook 库**：YAML 校验、支持归档导入、运行时注入额外变量。
- 保存/执行时自动做**高危检测**（见 4.6）。

### 4.6 高危命令与高危路径（防止误操作）

**高危命令**（`dangerousCommandDesc`）：**「配置高危命令规则，当用户执行匹配的命令时，将根据处理策略进行拦截或二次确认」**
- 匹配写法：**「支持普通字符串匹配和正则表达式」**，输入框占位 **「请输入命令关键字或正则表达式」**。

**高危路径**（`dangerousPathDesc`）：**「高危路径规则用于限制文件分发操作的目标路径，防止向系统关键目录分发文件」**
- 匹配写法：**「支持精确路径、通配符（*、**）和正则表达式。多个路径可用 | 分隔。」**

**处理策略**（两种，二选一）：
| 策略 | 命令场景 | 路径场景 |
|------|---------|---------|
| **禁止执行 / 禁止分发** | 直接拦截，不允许执行 | 直接拦截该路径，不允许分发 |
| **二次确认** | 弹窗提示用户确认后才能执行 | 弹窗提示确认后才能分发 |

- 新增入口：**「新增高危命令规则」/「新增高危路径规则」**。

### 4.7 看执行记录与仪表板

- **首页**：**「查看近 7 天或 30 天的作业执行趋势与成功率变化」**；含 **「成功率概览」**（**「当前周期成功率及相较上一等长周期的变化」**）、`执行次数/成功次数/失败次数`、`待执行`、`平均执行时长`、**「执行状态分布」**。
- **作业记录**：按状态 `执行中/成功/失败/已取消/超时`、来源 `手动执行/定时任务`、执行人筛选；点进看每台主机详情与完整日志。

## 5. 字段与配置项说明（速查）

| 项 | 说明 |
|----|------|
| 执行参数 | 与终端传参格式一致，如 `./test.sh a b c` |
| 超时时间(秒) | 超时自动终止 |
| 目标主机搜索 | 支持主机名/IP 模糊匹配 |
| 取消执行 | 仅请求取消，已下发部分可能仍执行 |
| 高危命令匹配 | 字符串或正则 |
| 高危路径匹配 | 精确/通配符(*、**)/正则，`|` 分隔多个 |
| 处理策略 | 禁止执行 或 二次确认 |
| 执行来源 | 手动执行 / 定时任务 |

---

## 6. 权限要求

- 执行受**目标团队归属**约束，非团队成员不能对目标执行。
- 编辑脚本库/Playbook、改高危规则、建定时任务：需作业管理角色。
- 高危命中时额外二次确认。

## 7. 常见问题（FAQ）

**Q：执行一直失败，日志说连不上目标。**
A：① 控制器是否在线（`06 节点管理`）；② 执行凭据是否有效；③ 网络端口；④ 作业记录里该主机的详细错误。

**Q：点了取消，目标机上命令还在跑。**
A：正常。取消只是"请求"（原文：**「已下发到目标主机的任务可能无法立即停止」**），远端可能跑完再回写结果，最终状态为"已取消"。

**Q：脚本保存/执行被拦截。**
A：命中「高危命令」规则。确认无误按提示二次确认；若正常业务被误拦，请管理员调整规则或把策略从"禁止执行"改为"二次确认"。

**Q：文件分发报路径被禁止。**
A：目标路径命中「高危路径」。改用合规路径，或让管理员调整规则（支持精确/通配符/正则）。

**Q：定时任务到点没跑。**
A：核对 Cron 表达式、时区、任务是否启用、团队凭据是否有效；到作业记录看是否有触发与失败原因。

**Q：动态目标执行时主机数和预期不符。**
A：动态目标是执行那刻从 CMDB 查的，资产变了结果就变。核对 CMDB 数据与筛选条件。

**Q：成功率统计和我想的不一样。**
A：首页成功率是**按周期对比**（较上一等长周期），且统计已完成执行的平均耗时，不含待执行。
